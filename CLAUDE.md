@AGENTS.md

## Claude Code

- Язык общения и документов — русский; код, идентификаторы и коммиты — на английском.
- Хуки (`.claude/settings.json`):
  - после каждой правки файл форматируется Prettier и чинится ESLint (`.claude/hooks/format-file.sh`);
  - правки `.env*` и уже закоммиченных миграций блокируются (`.claude/hooks/guard-edit.sh`);
  - при остановке запускаются `npm run typecheck` и `npm run lint`; если упали — нужно чинить, прежде чем заканчивать (`.claude/hooks/stop-check.sh`).
- Субагенты (модель Sonnet, задана во frontmatter): `spec-reviewer` — сверка диффа с ТЗ и AGENTS.md; `ui-verifier` — просмотр скриншотов из e2e и точечная проверка экрана в браузере.
- Браузер для проверки UI — Playwright MCP (`.mcp.json`); скриншоты для `docs/screens/` снимают e2e-сценарии (`SCREENS=task-NN npm run e2e`, хелпер `shot` в `e2e/fixtures.ts`), а не ручной проход.
- Оркестрация: основная сессия — оркестратор. Она не пишет код задач сама, а:
  1. запускает задачу по одной: субагент-исполнитель (`general-purpose`) выполняет скилл `/task N` в ветке `task/NN-<slug>`. Сначала исполнитель возвращает список открытых продуктовых вопросов (или «вопросов нет»); оркестратор задаёт их пользователю и передаёт ответы тому же исполнителю (SendMessage), только потом идёт реализация до коммита, без мёржа;
  2. проверяет результат сама: смотрит `git diff --stat` и нужные файлы (не весь дифф целиком), запускает `npm run check` (и `npm run e2e` при изменении UI), субагентов `spec-reviewer` и, если менялся UI, `ui-verifier` — по одному разу на задачу (исполнитель их не запускает);
  3. замечания возвращает тому же исполнителю (SendMessage); после правок проверяет сама — дифф правок, `check`/`e2e`; полное повторное ревью — только если правки большие, повторный `ui-verifier` — только если изменился вид экрана;
  4. когда задача готова по AGENTS.md — мёржит ветку в `main` fast-forward'ом и отчитывается пользователю;
  5. если ТЗ неполно или нужно продуктовое решение — останавливается и спрашивает пользователя.
- Формат коммита: `task NN: <что сделано>` (на английском), в конце — строка Co-Authored-By из системных инструкций.
