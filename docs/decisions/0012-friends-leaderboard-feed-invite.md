# 0012. Друзья: рейтинг, лента штампов, приглашение

Дата: 2026-10-11 · Задача: 10

## Контекст

ТЗ (экран 6) задаёт:

- рейтинг по странам, при равенстве — по блюдам;
- переключатель «Эта неделя / Всё время»;
- ленту до 20 штампов друзей;
- кнопку «Позвать друга в Telegram» и пустое состояние.

ТЗ не определяет:

- что считать штампом в ленте;
- формулировку записи (пол друга из Telegram неизвестен);
- вид записи без фото и формат времени;
- места при равенстве и период при открытии;
- поведение пустых состояний;
- способ отправки приглашения и его текст.

Имя бота и короткое имя приложения — открытый вопрос ТЗ.

Владелец продукта 2026-10-11 принял рекомендации исполнителя по всем пунктам.

## Решение

**Продуктовые правила (одобрены владельцем):**

**Лента**

- Штамп — первая готовка друга в стране. Повторные блюда в ленту не попадают.
- В ленте до 20 последних штампов всех друзей, новые сверху.
- Текст записи нейтральный к полу:
  - первая строка — «**Маша** — Грузия в паспорте»;
  - вторая строка — «Хачапури по-аджарски · 2 ч назад».
- Запись с фото показывает снимок друга 52 × 52. Запись без фото показывает нейтральную плитку с иконкой штампа; фото блюда из контента не подставляется.
- Время записи — по часовому поясу пользователя:
  - «только что» — меньше минуты назад;
  - «N мин назад» — меньше часа;
  - «N ч назад» — сегодня;
  - «вчера»;
  - старше — дата «12 октября», год — только если не текущий.
- Тап по записи и по строке рейтинга ничего не открывает.

**Рейтинг**

- Порядок: страны → блюда → имя.
- При полном равенстве стран и блюд место общее: 1, 2, 2, 4.
- Друзья без активности за неделю показываются с нулями.
- Строка пользователя — «Вы» с тёмным аватаром «Я».
- Подпись «N блюд» относится к выбранному периоду.
- «Эта неделя» — страны, первый штамп которых пришёлся на эту неделю, и все готовки недели. Неделя начинается в понедельник 00:00 по часовому поясу смотрящего.
- При открытии выбрана «Эта неделя». Выбор помнится, пока приложение открыто: слайс `friends`, лениво подключается.

**Пустые состояния**

- Друзей нет: карточка «Позовите друзей, чтобы соревноваться» с кнопкой приглашения. Рейтинг, строка «Вы» и лента скрыты.
- Друзья есть, штампов нет: под заголовком «Последние штампы» — «У друзей пока нет штампов».

**Приглашение**

- Ссылка `https://t.me/<бот>/<приложение>?startapp=<inviteCode>` отправляется через окно выбора чата Telegram `t.me/share/url` вызовом SDK `shareURL`, который делает `openTelegramLink`.
- Текст: «Готовлю ужины из кухонь разных стран и собираю штампы в паспорт. Присоединяйся — посоревнуемся!»
- Кнопка стоит в потоке после ленты, как в макете.

**Технические решения:**

- **`packages/shared/src/friends.ts`:**
  - `GET /friends/leaderboard?period=week|all` → `leaderboardResponseSchema` (`entries[]`: `userId`, `firstName`, `photoUrl`, `isMe`, `place`, `countries`, `dishes`);
  - `GET /friends/feed` → `feedResponseSchema` (`items[]` ≤ 20: кто, страна, блюдо, `photoUrl` — подписанная ссылка или `null`, `createdAt`);
  - чистые функции с юнит-тестами: `weekStart` (понедельник 00:00 в IANA-поясе с учётом перехода на летнее время), `firstStamps`, `buildLeaderboard`, `latestFriendStamps`.
- Сервер (задача 16) строит ответы теми же функциями. Часовой пояс берёт из `users.timezone` запрашивающего.
- **Имя бота и приложения:**
  - берутся из `VITE_BOT_USERNAME` и `VITE_APP_SHORT_NAME` (`.env.example`);
  - без них подставляются dev-заглушки `tma80_dev_bot` / `app`;
  - реальные значения задаются при запуске (задачи 18, 23).
- **Отправка приглашения:** `shareURL.ifAvailable`; если метод недоступен (вне Telegram) — `window.open` той же ссылки `t.me/share/url`.
- **Кеш RTK Query:** рейтинг помечен тегом `Cooks` и обновляется после своей готовки; ленту меняют только готовки друзей, поэтому тега у неё нет.
- **Ошибки:** ошибка рейтинга при первой загрузке занимает весь экран с «Повторить». Ошибка ленты показывается в своём блоке со своим «Повторить», рейтинг остаётся на экране.
- **Мок:**
  - обработчики `GET /friends/leaderboard` (ключ `?mock_error=friends`) и `GET /friends/feed` (ключ `friends_feed`);
  - у части готовок друзей в фикстурах есть фото: `photoPath` в папке друга, вместо подписанной ссылки — SVG-«снимок» `mockCookPhotoUrl`.
- **Компонент `SegmentedControl`:** сегментный переключатель вынесен с главного экрана в `src/components/` и добавлен в `/dev/ui`.

## Альтернативы

- Лента из всех готовок друзей: повторы вытеснили бы новые страны, а в ТЗ речь именно о штампах.
- «Открыла(а)» или пол из имени: выглядит небрежно, а угадывание пола по имени ненадёжно.
- `shareMessage` с подготовленным сообщением: нужен бот и сервер (задачи 18 и 20). Окно `t.me/share/url` работает во всех клиентах уже сейчас.
- Места подряд при равенстве: в понедельник утром у всех 0/0 получалось бы «1, 2, 3, 4» без причины.

## Последствия

- Задача 16: эндпоинты `/friends/*` на сервере используют `buildLeaderboard` и `latestFriendStamps`; `photoUrl` в ленте — подписанная ссылка nginx на 1 час (задача 17).
- Задачи 18 и 23: задать `VITE_BOT_USERNAME` и `VITE_APP_SHORT_NAME` для продакшен-сборки.
