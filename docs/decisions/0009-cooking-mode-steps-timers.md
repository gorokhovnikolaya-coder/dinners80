# 0009. Режим готовки: подстановка количеств, навигация, таймеры, wake lock

Дата: 2026-10-10 · Задача: 07

## Контекст

ТЗ (экран 3) задаёт один шаг на экране, подстановку количеств по `{key}`, таймер, wake lock и отключение свайпов, но не определяет: что именно подставляется вместо `{key}` (в модели только имя в именительном падеже), подсказки под шагом из макета, навигацию между шагами и выход, поведение нескольких таймеров, сигнал и судьбу прогресса после «Готово!». Владелец продукта 2026-10-10 принял рекомендации исполнителя; правила внесены в ТЗ (экран 3, модель данных — правило контента, «Принятые решения»).

## Решение

**Продуктовые правила (одобрены владельцем):**

- `{key}` заменяется только количеством с единицей («400 г», «1,5 шт», пересчёт по порциям тем же `scaleAmount`); существительное в нужном падеже автор пишет после плейсхолдера: «Обжарьте {beef} говядины». У ингредиентов «по вкусу» плейсхолдеров нет. Количество в тексте выделено (`mark`, accent-soft, как в макете).
- Подсказки под шагом (есть в макете) в MVP не делаем — поля в `dish_steps` нет.
- Внизу «Назад» (предыдущий шаг; на первом неактивна) и «Следующий шаг», на последнем — «Готово!». Системная «Назад» Telegram — на карточку блюда без подтверждения (при прямом входе — тоже на карточку, `useGoBack(dishPath)`); «×» — только запасная кнопка, если системной нет (`BackNavigation` с иконкой и подписью «Закрыть режим готовки»).
- Шаг и таймеры держатся, пока приложение открыто (Redux, по блюду): «Начать готовить» продолжает с того же шага.
- Таймер у каждого шага свой, идти могут несколько. Кнопка: «Запустить таймер» → «Пауза» → «Продолжить»; «Сбросить таймер» — когда таймер запускали. Идущие, на паузе и закончившиеся таймеры других шагов — строкой «Шаг N · m:ss» / «Шаг N · время вышло», нажатие открывает шаг.
- По окончании (если режим открыт) — вибрация, звук, «Время вышло» на кнопке и в `role="status"`. Таймер, закончившийся вне режима, сигнала не даёт — при возврате видно «Время вышло».
- «Готово!» сбрасывает шаг и таймеры блюда и ведёт на `/dishes/:id/done` (экран фото и штампа, задача 8) с заменой записи истории; до задачи 8 роутер уводит на главный.

**Технические решения:**

- `splitStepText`, `stepPlaceholderKeys`, `findStepPlaceholderProblems` (неизвестный ключ, ключ «по вкусу») — в `packages/shared/src/steps.ts`; тест фикстур и будущий seed (задача 14) проверяют контент ими.
- Таймер хранит момент окончания (`endsAt`), а не остаток: время идёт верно в фоне и на других экранах. Чистые функции — `screens/cooking/timers.ts`, состояние — ленивый слайс `cooking` (`step`, `timers` по номеру шага). Экран перерисовывается каждые 250 мс, только пока идёт хотя бы один таймер; если WebView свёрнут, браузер притормаживает интервал, и сигнал прозвучит при возвращении.
- Сигнал: `hapticFeedback.notificationOccurred('warning')`, где недоступно — `navigator.vibrate`; звук — три коротких тона Web Audio (без файла в бандле), `AudioContext` разблокируется нажатием «Запустить таймер» (iOS/Chrome требуют жест). «Следующий шаг» и «Готово!» — `impactOccurred('medium')` (ТЗ: тактильная отдача на завершении шага).
- Wake lock — `navigator.wakeLock.request('screen')` при входе, повторно на `visibilitychange` (браузер снимает его при скрытии), снимается при выходе; строка «Экран не погаснет, пока вы готовите» видна, только пока lock действительно взят.
- Свайпы: `swipeBehavior` монтируется при запуске SDK; `useVerticalSwipesDisabled` вызывает `disableVertical.ifAvailable()` на входе и `enableVertical.ifAvailable()` на выходе. Клиенты без метода (Mini Apps < 7.7) свайпы сохраняют — запасного варианта нет и не нужно.
- Данные — тот же `GET /dishes/:id`: экран ищет в кеше RTK Query загруженный запрос этого блюда (`selectLoadedDishArgs`) и подписывается на те же аргументы — без нового запроса, а при обрыве связи шаги остаются (кеш в памяти, НФТ «рецепт кешируется»). Порции — `selectServings` карточки, иначе `servings` ответа. `403` → пейвол, `404` → «Блюдо не найдено».
- Фон экрана — `bg` (как шапка Telegram), а не белый из макета, чтобы шапка и экран не расходились по цвету.

## Альтернативы

- **Подставлять «название (количество)» или добавить `name_gen`** — первое ломает падеж, второе меняет модель данных и заставляет заполнять форму каждого ингредиента.
- **Один активный таймер** — проще, но у блюд бывают два долгих таймера подряд (лазанья: 40 + 40 мин).
- **Остаток в секундах с уменьшением по интервалу** — сбивается в фоне, где интервалы тормозятся.
- **Аудиофайл сигнала** — лишний запрос и вес; Web Audio хватает.
